# BookToCards

BookToCards creates flashcards from Japanese material for learning kanji and
vocabulary. `README.md` gives the installation steps.

## Commands

```shell
make format                 # black and isort
make lint                   # flake8
make check_type             # mypy
pytest                      # tests
pre-commit run --all-files  # all of the above, as checks
```

## Project files

Before a task, read the project files that exist. `docs/agentic_coding.md`
describes them. Name code after the terms in `CONCEPTS.md`.
